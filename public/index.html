FAQ
Serve para qualquer concurso?
Sim. O ciclo é universal: plano (tema/pdf) + prática + revisão por métricas.
Preciso de cartão para testar?
Não. O gratuito é para você experimentar o fluxo completo antes de assinar.
Como funciona o Founder?
Founder é uma condição especial de lançamento. Cupom público: FOUNDER30. O desconto vale enquanto a assinatura permanecer ativa.
